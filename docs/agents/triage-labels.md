# Triage labels

| Label             | Meaning                                       |
| ----------------- | --------------------------------------------- |
| `needs-triage`    | Awaiting maintainer evaluation                |
| `needs-info`      | Awaiting information from the reporter        |
| `ready-for-agent` | Fully specified for autonomous implementation |
| `ready-for-human` | Requires human implementation                 |
| `wontfix`         | Will not be implemented                       |

Use these exact labels when a skill refers to a triage role.
